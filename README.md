# Karo – Mathe und Englisch üben

Lern-App für Klasse 5 bis 10: Erklärungen, Übungen mit Tipps und Lösungsweg, Tests mit Note,
Englisch-Grammatik, Vokabeltrainer und Übungsblätter zum Ausdrucken.

Kostenlos, ohne Werbung, ohne Anmeldung. Der Fortschritt bleibt nur im eigenen Browser gespeichert.

Öffnen: https://elias1234491.github.io/

## Auf allen Geräten speichern

Im Profil kann man einen geheimen Karo-Code erstellen. Damit liegt der Fortschritt zusätzlich im
Karo-Speicher (Netlify-Funktion `netlify/functions/karo.mjs`, gespeichert mit Netlify Blobs).
Es wird kein Name und keine E-Mail verlangt; gespeichert wird unter einer Prüfsumme des Codes.
